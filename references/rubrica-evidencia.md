# Rubrica de evidências, responsabilidade e proficiência

## Origem da afirmação

- **Depoimento:** pessoa relatou diretamente, sem verificação independente.
- **Documento pessoal:** currículo, notas ou material fornecido pela pessoa.
- **Artefato técnico:** código, notebook, gráfico, relatório ou aplicação efetivamente inspecionada.
- **Fonte externa:** publicação ou registro verificável.
- **Inferência:** interpretação do agente a partir das evidências; não é fato.
- **Desconhecido:** ausência de informação, memória incerta ou incompatibilidade não resolvida.

## Qualificadores

**Precisão:** exato / aproximado / não informado / conflitante.
**Papel:** executou / projetou / implementou / operou / manteve / coordenou / recomendou / participou / equipe fez / decisão de terceiros.
**Resultado:** medido / estimado / observado qualitativamente / planejado / não observado.
**Divulgação:** privado / compartilhável após revisão / público autorizado.

Exemplos de diferenciação:
- 1.500 contratos processados não significa 1.500 renegociações concluídas.
- Contratos comerciais fechados não equivalem a receita recebida.
- Economia estimada por adiar um investimento não é economia comprovadamente realizada.
- Participar da investigação não significa decidir o julgamento.
- A/B com escolha manual dos tratados não demonstra aleatorização.
- Correlação temporal, por si, não comprova causa ou acordo ilícito.
- Criar uma automação não prova aumento de lucro em um programa cujo resultado comercial foi limitado.

## Cinco dimensões de competência

Avalie fundamentos, execução, complexidade, autonomia e produção separadamente em 0–4 **somente com evidência suficiente**. Caso contrário use ?. O objetivo não é produzir um placar automático de senioridade.

0. Ausência de experiência demonstrada.
1. Contato inicial ou atividade guiada.
2. Aplicação delimitada.
3. Execução autônoma de problemas reais.
4. Arquitetura, diagnóstico de falhas, trade-offs e evolução comprovada em problemas complexos.

A escala é um roteiro de aprofundamento, não uma certificação. Registre sempre o caso que fundamenta o grau atribuído.

## Auditoria antes de publicar

Verifique título formal, datas, número, escala, período, método realmente utilizado, papel pessoal, compartilhamento de resultado, impacto causal, artefato de origem e autorização para divulgação. Não preencha lacunas por analogia.

## Correções

Quando a pessoa retificar um fato, atualize imediatamente a versão vigente, acrescente uma entrada ao histórico e preserve o original apenas como registro histórico, não como hipótese igualmente sustentada. Se houver contradição não resolvida, sinalize a divergência.

## Dados sensíveis

Nunca publique dados de clientes, credenciais, saldos, relatórios internos, incidentes identificáveis ou dados pessoais de terceiros. Para currículo público, generalize a descrição sem distorcer a contribuição.
